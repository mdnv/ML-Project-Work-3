# Предобработка данных игроков — ПР-3, уровень B

Проект демонстрирует предобработку датасета `players.csv` с помощью `Pipeline` и `ColumnTransformer` без утечки данных.

## Структура

- `data/players.csv` — исходные данные.
- `notebooks/preprocessing_B.ipynb` — код, проверки и обоснование выбранных стратегий.

## Обработка данных

- Разбиение на train/test: 80/20.
- Числовые признаки: заполнение медианой и `StandardScaler`.
- Категориальные признаки: заполнение категорией «неизвестно» и `OneHotEncoder`.
- Вычисление возраста по дате рождения и дате снимка.
- Исключение идентификаторов, имён, полностью пустых и неинформативных столбцов.

Пайплайн обучается только на train. Для test используется `transform` без повторного обучения.

## Запуск

1. Установить зависимости:
   ```bash
   pip install pandas numpy scipy "scikit-learn>=1.2" ipykernel
   ```
2. Открыть ноутбук в VS Code с расширениями Python и Jupyter.
3. Выбрать ядро Python и проверить путь к CSV.
4. Выполнить ячейки сверху вниз.
